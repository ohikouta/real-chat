# システムテストケース

ブラウザ上の画面操作を通じて、Real Chat全体の画面遷移・表示とFirebaseへの保存結果を確認するケースを定義する。各ケースは隔離されたテスト環境とテストデータで実施する。

| ケースID | 前提・操作 | 期待結果 | 実行結果・観察 | 実施日 | コミット・環境 |
|---|---|---|---|---|---|
| SYS-ROUTE-001 | 未認証で`/`を開く | Home画面が表示される | | | |
| SYS-ROUTE-002 | 未認証で`/users`を開く | `/login`へ移動する | | | |
| SYS-ROUTE-003 | 未認証で`/profile`を開く | `/login`へ移動する | | | |
| SYS-ROUTE-004 | 未認証で`/timeline`を開く | `/login`へ移動する | | | |
| SYS-ROUTE-005 | 未認証で有効な投稿IDの`/timeline/:postId/thread`を開く | `/login`へ移動する | | | |
| SYS-ROUTE-006 | 未認証で`/chat/:userId`を開く | `/login`へ移動する | | | |
| SYS-ROUTE-007 | 認証済みで`/login`を開く | `/`へ移動する | | | |
| SYS-ROUTE-008 | 認証済みで`/register`を開く | `/`へ移動する | | | |
| SYS-AUTH-001 | 未登録のメールアドレス、パスワード、表示名を入力して登録する | Authアカウントと`users/{uid}`が作成され、プロフィール画面へ移動する | | | |
| SYS-AUTH-002 | 必須入力の一部を空にして登録する | 登録処理が行われず、必須項目のエラーが表示される | | | |
| SYS-AUTH-003 | 有効な登録済みメールアドレスとパスワードでログインする | Homeへ移動し、認証必須画面を開ける | | | |
| SYS-AUTH-004 | 誤ったパスワードでログインする | ログインできず、画面上にエラーが表示される | | | |
| SYS-AUTH-005 | ヘッダーからログアウトし、認証必須画面を開く | ログアウト後に未認証状態となり、ログイン画面へ誘導される | | | |
| SYS-USER-001 | AliceとBobを作成し、Aliceで`/users`を開く | 自分自身は一覧に含まれず、Bobの表示名とオンライン状態が表示される | | | |
| SYS-USER-002 | ユーザー一覧でBobを選択する | `/chat/{Bobのuid}`へ移動する | | | |
| SYS-PROFILE-001 | プロフィール画面で表示名と画像URLを変更して保存し、再読み込みする | 保存した値が再表示される | | | |
| SYS-PROFILE-002 | 表示名を空にしてプロフィールを保存する | 保存されず、入力エラーが表示される | | | |
| SYS-PROFILE-003 | プロフィール画面で対応形式・容量の画像をアップロードする | 画像が保存され、プロフィール画面と再読み込み後の画面に反映される | | | |
| SYS-DM-001 | AliceとBobが同じDMを開き、Aliceからメッセージを送る | メッセージが保存され、両方の画面に送信者名と本文が表示される | | | |
| SYS-DM-002 | Bobから返信を送り、Alice側の会話を確認する | 新着メッセージがリアルタイム反映され、送信順に表示される | | | |
| SYS-DM-003 | Aliceが空白だけのメッセージを送信する | メッセージは保存されない | | | |
| SYS-THREAD-001 | 認証済みユーザーでタイトルと本文を入力して投稿する | スレッドが保存され、`/timeline`に新着順で表示される | | | |
| SYS-THREAD-002 | タイトルまたは本文を空にして投稿する | 投稿されず、入力エラーが表示される | | | |
| SYS-THREAD-003 | スレッド詳細を開き、認証済みユーザーでコメントを投稿する | コメントが対象スレッド配下に保存され、詳細画面に表示される | | | |
| SYS-THREAD-004 | 複数ユーザーが同じスレッドにコメントする | コメントが作成順に表示され、参加者が重複なく表示される | | | |
| SYS-THREAD-005 | コメント本文を空にして送信する | コメントは保存されない | | | |
